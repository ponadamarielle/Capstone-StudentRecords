# Super Admin Password Reset

1. Start MySQL in the XAMPP Control Panel.
2. Open Command Prompt (CMD).
3. Run the following command:

   ```cmd
   C:\xampp\php\php.exe C:\xampp\htdocs\CAPSTONE\tools\reset_superadmin_password.php
   ```

4. If multiple Super Admin accounts exist, enter the email address of the account to reset.
5. Verify the account details, type `YES`, and press Enter.
6. Copy the generated temporary password. Keep it private.
7. Sign in to PUP eRecords using the Super Admin email and temporary password.
8. Change the temporary password to a new strong password.
